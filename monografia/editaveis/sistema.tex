\chapter{Sistema de Previsão e Alerta}
\label{cap:sistema}

Os resultados da pipeline mesorregional foram disponibilizados por meio de quatro componentes, descritos neste capítulo: um painel interativo em Streamlit, uma pipeline automatizada de atualização, a publicação dos dados em repositório aberto e notebooks reprodutíveis.

\section{Dashboard DengueCast v4}

O painel principal do projeto é uma aplicação Streamlit \cite{streamlit2024} hospedada no Streamlit Community Cloud\footnote{Disponível em \url{https://modelo-previsao-ffqc3ugltpbxxeaa4mygvw.streamlit.app}.}. A interface permite:

\begin{itemize}
    \item Filtrar por UF e intervalo de anos;
    \item Visualizar a série temporal observada e prevista de notificações por mesorregião;
    \item Consultar o mapa de alertas de surto com classificação em quatro faixas de risco;
    \item Inspecionar a importância das variáveis pelo SHAP;
    \item Explorar os dados brutos e as métricas do modelo.
\end{itemize}

O dashboard utiliza os modelos de regressão e classificação da v4 e os dados de teste para gerar previsões e alertas. Os dados são carregados a partir do repositório no HuggingFace.

\section{Pipeline Automatizado}

A atualização dos dados é realizada por um workflow do GitHub Actions configurado no repositório MODELO-PREVISAO \cite{modeloprevisao2026}. O fluxo opera em dois modos:

\begin{itemize}
    \item \textbf{Atualização semanal (cron):} às segundas-feiras às 03h (horário de Brasília), o workflow busca os dados mais recentes do SINAN e carrega os ZIPs brutos no HuggingFace, sem executar a pipeline de treino;
    \item \textbf{Re-execução completa (manual):} via \texttt{workflow\_dispatch}, é possível disparar a execução da pipeline v4 completa (scripts~40-55), com criação de swap de 8~GB para caber no runner gratuito de 7~GB de RAM.
\end{itemize}

\section{Publicação de Dados}

Todos os artefatos do projeto --- dados brutos, dados processados (bronze, silver e gold do SINAN e do INMET), datasets de treino e teste, modelos treinados, relatórios JSON e figuras --- estão publicados no HuggingFace Datasets\footnote{Disponível em \url{https://huggingface.co/datasets/pedrolucassantanaf/dengue-tcc2-data}.}, totalizando aproximadamente 4.400~arquivos e 4~GB. A publicação permite a reprodução completa dos experimentos sem acesso aos servidores originais.

\section{Notebooks Reprodutíveis}

Três notebooks públicos no Kaggle\footnote{Disponíveis em \url{https://www.kaggle.com/pedrolucassantana}.} documentam a exploração dos dados, o treino do modelo e a análise dos resultados:

\begin{enumerate}
    \item \textbf{Exploração:} estatísticas descritivas, cobertura do INMET, distribuição das notificações;
    \item \textbf{Treino:} reprodução do treino XGBoost com os mesmos hiperparâmetros de \texttt{config/recorte.json};
    \item \textbf{Resultados:} tabelas e figuras comparativas entre variantes e baselines.
\end{enumerate}
